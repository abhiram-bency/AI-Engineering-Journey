# Transformer from Scratch using PyTorch

## Overview

This project implements the Transformer architecture from the paper **Attention Is All You Need** using fundamental PyTorch operations.

The goal is to understand each component of the architecture by implementing it step by step, without using high-level modules such as:

- `torch.nn.Transformer`
- `torch.nn.MultiheadAttention`

## Planned Componentsgit

- Token Embeddings
- Positional Encoding
- Scaled Dot-Product Attention
- Multi-Head Attention
- Feed Forward Network
- Layer Normalization
- Residual Connections
- Encoder
- Decoder
- Complete Transformer
